# Knowledge Index

> 这是 `03_Knowledge/` 的内容入口，不是文件树。每次 Ingest 或有长期价值的 Query 写回后，更新受影响条目；示例文件不计入正式知识。

## 使用方式

1. 回答知识问题时先读本页，再进入相关 Topic 和卡片。
2. 新页面进入正式知识区时加入索引；归档后移除。
3. 一句话说明写“页面能回答什么”，不复制正文摘要。
4. `来源数` 按页面中可识别的独立来源估计；无法可靠判断时写 `—`。
