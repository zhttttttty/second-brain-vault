# Archive

`06_Archive/` 保存已经退出 Daily、Projects、Knowledge、References 或 Tasks 活跃工作流，但仍因追溯、复用或合规需要保留的历史内容。

## 归档原则

- 归档不是删除，也不是新的分类入口。
- 只有内容已经不再活跃、但未来仍可能需要追溯时才迁入。
- 项目归档时保留完整项目目录，避免拆散决策、产出和附件。
- 默认会话定向、今日计划和知识检索不优先读取本目录。
- 需要恢复时移回最合适的活跃目录，并同步更新相关任务、链接或索引。
