# GLOSSARY.md — 全书共享术语词典

> 本词典包含「1小时构建知识体系」中所有关键概念的作者用法定义。
> 它是所有 skill 的共享参考，不应被埋在审计目录里。

## 一、世界观层 · 关于世界本身

| 术语 | 作者的用法 | 和常识的差异 |
|---|---|---|
| 物质世界 | 你看到的、流变的、瞬息万变的表象世界 | 常识指物理世界；这里特指「可感知但不可依靠的表象」 |
| 法则世界 | 物质世界背后永恒不变的运行规则 | 常识无此用法；作者独创的二元划分 |
| 世界观 | 对「世界是什么、怎么运行」的理解，解决「是什么/为什么」 | 常识泛指人生观+价值观；这里 narrower，聚焦认知框架 |
| 方法论 | 基于世界观找到的「如何解决问题」的方法、步骤、方案 | 常识偏学术；这里强调「从规律推导出的行动指南」 |

## 二、知识体系层 · 关于知识本身

| 术语 | 作者的用法 | 和常识的差异 |
|---|---|---|
| 知识点 | 知识的最小单位，一句话能讲清的事实或观点 | 与常识基本一致 |
| 模型 | 把多个知识点浓缩成的 4–5 个字的核心认知 | 常识指数学/物理模型；这里是认知压缩单元 |
| 知识体系 | 严格按关系联结的「模型的集合」 | 常识认为是「知识的集合」；作者强调「关系」才是核心 |
| 关系 | 知识体系的真正核心，决定体系能否「活」起来 | 常识视为辅助概念；作者将其置于最高位 |
| 因果关系 | A 导致 B 的横向推动关系 | 与常识基本一致，但特化为知识体系的结构要素 |
| 层次关系 | A 包含 B 的纵向包含关系 | 与常识基本一致，但特化为知识体系的结构要素 |

## 三、模型提炼层 · 关于如何提炼

| 术语 | 作者的用法 | 和常识的差异 |
|---|---|---|
| 拆解 | 把内容拆成独立单句，每句单独可读 | 与常识基本一致 |
| 淘金 | 从句子里识别世界观/方法论价值 | 作者自创的比喻，强调「筛选」而非「收集」 |
| 理解 | 标 3–5 个关键词，抓作者核心意图 | 强调「关键词 = 世界观类 or 方法论类」 |
| 判断 | 评估知识的正误 + 知识关系的合理性 | 分两个层次：单知识判断 + 关系判断 |
| 启发 | 把价值提炼成 4–5 个字的模型 | 强调「压缩」和「可传播性」 |

## 四、知识存储层 · 关于如何存

| 术语 | 作者的用法 | 和常识的差异 |
|---|---|---|
| 序号 | 每个知识点标 1、2、3...，独立可修剪 | 强调「可修剪性」而非单纯的编号 |
| 关键词 | 按重要性标粗 | 强调「重要性排序」而非简单标记 |
| 出处 | 必须标注来源 | 强调「可考证性」 |
| 思考 | 自己的理解必须及时记录 | 强调「不及时记录必忘」的紧迫性 |
| 证伪 | 模型要有足够反例/反证才能成立 | 引入波普尔科学哲学，但用于个人知识管理 |

## 五、行为与成长层

| 术语 | 作者的用法 | 和常识的差异 |
|---|---|---|
| 行为改变三层次 | 结果 → 过程 → 身份 | 源自 James Clear《Atomic Habits》，课件未标注来源 |
| 匪气 | 普通人要有点匪气，主动争取机会 | 情绪性表达，非严格方法论 |
| 自律 | 起于微目标，通过内啡肽/多巴胺自然提升 | 强调生理机制（内啡肽）而非意志力 |
