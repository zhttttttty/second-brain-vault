# 知识密度分层 T1/T2/T3 (v0.3)

> 修补的作者局限: 附篇 21 个生活小妙招和「匪气」「时间宝贵」等内容属于常见鸡汤，方法论密度低，拉低了整体含金量。
> 应对策略: **不是删除，而是分层**。知识体系不应该是平的。低密度内容的价值是「触发器」——某天撞到相关场景时能检索到就够了。

## 三层结构

| 层级 | 内容 | 处理方式 | 示例 |
|------|------|---------|------|
| **T1 核心方法论层** | 通过三重验证的模型 | 进入主工作流，RIA++S 完整重构 | 6 步法、知识价值二元判断法、5 步模型提炼 |
| **T2 可提炼层** | 有模型结构但未提炼 | 提炼升级到 T1 | 「复盘」→ 反馈回路模型、「精力管理」→ 资源调度模型 |
| **T3 参考层** | 纯行为清单、无结构 | 检索素材 + 触发器，不进工作流 | 105 条生活小妙招的大部分、「匪气」 |

## 判断标准（只有一条）

能否回答「它的**要素 / 关系 / 步骤 / 序列**是什么？」

```
能        → 提炼成模型，升级 T1
模糊      → 挂在 T2 待观察
不能      → 定 T3，接受它是触发器
```

快捷判别法: 删掉它，你的行为系统失去的是一个「**结构**」还是仅仅一个「**选项**」？
失去结构的是 T2 候选；只失去选项的是 T3。

## T2 → T1 提炼示范

「复盘」（生活管理第 18 招: 每日三省吾身，找到卡点，单点突破）提炼为模型:

```
复盘 = 反馈回路模型
  要素: 目标 / 执行记录 / 差异 / 修正动作
  步骤: 目标回顾 → 差异分析 → 单点突破 → 行为修正
  关系: 差异驱动修正（因果）; 复盘嵌套于执行循环（层次）
  source: 改编自 PDCA 循环 (Deming)，作者口语化为「三省吾身」
```

对比 T3 的例子: 「早起，你将比别人多出半天的精彩」——拆不出要素关系步骤序列，它是行为清单 + 情绪激励，定 T3。

## T3 的正确用法

T3 不是垃圾，是**触发器**:

1. **检索价值**: 用户说「我想养成运动习惯」时，运动 21 招立即提供 21 个候选动作
2. **场景匹配**: T3 内容自带场景标签，比抽象模型更快匹配具体需求
3. **克制升级冲动**: T3 数量庞大（105 条），全部强行提炼会稀释 T1 的信噪比——这正是源课件犯的「常识稀释」错误，不要在修复时重犯

## 边界

- **分层不是一次性的**: T3 内容被反复用到时，随时可启动提炼流程升 T2
- **分层是主观的**: 同一内容对不同人层级不同——对健康领域从业者，养生 21 招可能是 T1 素材
- **别用分层做拖延借口**: 「等我分好层再开始」违背方法的行动优先原则——先跑起来，边用边分层
