# 个人知识体系四维图 · Personal Knowledge Dimensions

> 来源：第 20 张图（个人知识体系构建思维导图）

## 总体结构

个人知识体系由 **4 大维度** 构成：

```
个人知识体系
├── 1. 素质 (Quality)       —— 内在的底色
├── 2. 能力 (Ability)        —— 解决问题的能力
├── 3. 技能 (Skills)         —— 可操作的具体方法
└── 4. 知识 (Knowledge)      —— 储备的认知
```

---

## 1. 素质 (Quality)

素质 = 先天 + 后天

| 子类 | 内容 | 是否可改变 |
|------|------|-----------|
| **先天** | 性格 | 难改（但可训练应对方式）|
| 先天 | 身高 | 不可改 |
| 先天 | 容貌 | 微调 |
| **后天** | 价值观 | 可塑造（核心）|
| 后天 | 习惯 | 可训练（核心）|

**自检问题：**
- 我的价值观是什么？写下来了吗？
- 我的核心习惯有哪些？哪些需要改？

---

## 2. 能力 (Ability)

能力 = 个人能力 + 团队能力

| 子类 | 内容 |
|------|------|
| **个人能力** | 思维力（思考问题的方式）|
| 个人能力 | 学习力（学习新事物的速度）|
| 个人能力 | 表达力（清晰传递信息）|
| **团队能力** | 沟通能力（与他人协作）|
| 团队能力 | 领导能力（带领团队）|

**自检问题：**
- 我最强的能力是哪个？最弱的是哪个？
- 我现在的岗位最需要哪 3 项能力？

---

## 3. 技能 (Skills)

技能 = 通用技能 + 专业技能

| 子类 | 内容 |
|------|------|
| **通用技能** | 时间管理 |
| 通用技能 | 精力管理 |
| 通用技能 | 软件技能（Office/AI工具等）|
| **专业技能** | 自己所在岗位专业技能 |

**自检问题：**
- 我的时间管理方法是什么？
- 我常用的提效软件有哪些？还在用 5 年前的工具吗？
- 我岗位的 TOP 3 专业技能是哪些？掌握了几个？

---

## 4. 知识 (Knowledge)

知识 = 通用知识 + 专业知识

| 子类 | 内容 |
|------|------|
| **通用知识** | 心理学（理解人）|
| 通用知识 | 育儿知识（如果有孩子）|
| 通用知识 | 社会常识（理解社会）|
| **专业知识** | 自己岗位的专业知识 |

**自检问题：**
- 我对人性/心理学的了解够吗？
- 我能跟各行各业的人聊起来吗？
- 我岗位的知识更新到最新版本了吗？

## 配套学习体系 1.0

> 来源：第 21 张图（知识体系搭建）

构建个人知识大厦的 7 个子体系：

| 子体系 | 数量 | 内容 |
|--------|------|------|
| 知识树 | 5 | 知识本身 |
| 记忆树 | 5 | 记忆方法 |
| 思考树 | 4 | 思维方式 |
| 学习树 | 3 | 学习方法 |
| 学习方法树 | 3 | 学习方法本身 |
| 学习之道 | 3 | 学习的本质 |
| 待解决问题 | 2 | 需研究的问题 |

**核心理念：**
> "世间的万物都是一个相互作用的整体。人类所有的知识都是对这一整体研究的部分尝试。只有把这些知识结合起来，并贯穿在一个思维框架中，才能对正确的认知和决策起到帮助作用。" ——《穷查理宝典》

> "世界是普遍联系的。" ——《马哲》

> "如果我们试图理解一个看似独立存在的东西，将会发现它和宇宙的其他一切都有联系。" ——约翰·缪尔

> "所谓的学习就是把原本不相关的东西联系在一起的过程。"

## 一张图搞定：学习体系

> 来源：第 18 张图

```
输入 → 内化 → 应用

输入：
- 目的：当前专业 / 兴趣 / 未来方向
- 渠道&教材：跟谁学 / 借网络 / 看书
- 标标准、目标

内化：
- 人（成长经历 / 信念系统 / 行为方式）
- 事（关键因素 / 流程 / 任务 / 目标 / 路径 / 标准 / 复盘）
- 网（新动态）
- 课（新认知 / 方法 / 体系 / 案例）
- 书（同上）
- 拆解 → 理解 / 记忆 / 应用
  - 拆成功因素
  - 拆逻辑框架 / 核心知识
  - 形成记忆分析 → 行动指南
- 创造为主 / 整理为辅

应用：
- 知识分享（笔记 / 写作）
- 解决问题（融会贯通 / 迁移应用 / 原创方法）
- 能力提升（他人背书 / 案例 / 框架）
- 获得成绩（薪资 / 职位 / 权力 / 名声）
- 形成闭环
```

---

## 如何用这张图

### 自检流程
1. 按 4 维度（素质/能力/技能/知识）逐项打分
2. 找出最弱的一项
3. 设计 3-6 个月提升计划
4. 每月回顾调整

### 提升原则
- **素质层最难改但最重要**（价值观+习惯）
- **能力层比技能层更值钱**（能力可迁移，技能易过时）
- **知识层最易堆积但最易过期**（需定期更新）

### 与 6 步法的关系
- 这张图是 **Step 2（理解知识体系本质）** 在个人维度的具体应用
- Step 5（组成体系）时，可以直接套用这 4 维作为框架
